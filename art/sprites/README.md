# Sprites — 2D icons & UI art

This folder is for 2D assets: creature roster icons, type/element icons, UI portraits, item icons — anything flat/2D rather than the 3D models in `art/creatures/` and `art/environments/`.

Nothing has been sourced for this folder yet. None of the packs found so far (Quaternius, KayKit, Meshtint) are sprite/icon packs — they're all 3D models. Options once we get here:

- Render icons from the 3D creature models (in-engine icon-camera renders) once creature models are in place — usually the best match visually
- A separate free 2D icon pack (e.g. game-icons.net for silhouette-style UI icons, CC-licensed)
- Original 2D art once/if an artist joins the team

## Folder convention

```
art/sprites/icons/         UI icons (items, currencies, buttons)
art/sprites/portraits/     creature/character portraits
art/sprites/ui/            other 2D UI art (frames, backgrounds)
```
