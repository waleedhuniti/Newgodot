## Converted formats

`client/public/models/*.glb` are glTF conversions of the FBX files in this folder (via Blender, all animation actions preserved as separate glTF animation clips), used directly by the web client. The FBX/OBJ/Blend files here are the pristine originals — don't edit them in place; redo the conversion if a fix is needed.
